# コミットメッセージを日本語にする方法

VS Code の設定で、**コミットメッセージ生成専用の指示**を追加してください。

1. コマンドパレットから **Preferences: Open User Settings (JSON)** を開く
2. 次の設定を追加して保存する

```json
"github.copilot.chat.commitMessageGeneration.instructions": [
  {
    "text": "コミットメッセージは日本語で生成してください。変更内容を簡潔に要約してください。"
  }
]
```

ユーザー設定に入れると、どのリポジトリでも適用されます。特定のリポジトリだけに適用する場合は、ワークスペース設定に追加します。

なお、`.github/copilot-instructions.md` の指示は、VS Code のソース管理にあるコミットメッセージ生成ボタンには適用されません。上記の専用設定を使ってください。設定の詳細は [VS Code のドキュメント](https://code.visualstudio.com/docs/agent-customization/custom-instructions#_specify-instructions-for-generated-content)を参照してください。
