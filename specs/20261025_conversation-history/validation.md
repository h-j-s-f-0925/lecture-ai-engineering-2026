# 検証方法と完了条件

## 自動テスト

- API モックを使い、2ターン目に以前の `user` / `model` 発話と今回の質問が順番どおり `generate_content` に渡ることを確認する。
- API モックを使い、履歴がある場合だけ `count_tokens` が過去の発話だけを計数し、表示上の「履歴」と「入力全体」が区別されることを確認する。履歴がない場合は計数APIを呼ばず、履歴数を0と表示する。
- `/exit` と `/quit` で、追加の API 呼び出しなしに対話ループが終了することを確認する。
- 既存の単発質問、`--temperature`、トークン表示に関するテストを維持する。
- Gemini API への実リクエストや API キーを必要としない方法で検証する。

## 手動確認手順

1. Gemini APIを利用できる環境で、`uv run python -m app.ask` を実行する。
2. 1つ目の質問として `LoRAとは何ですか` を入力し、回答が表示されることを確認する。
3. 2つ目の質問として `AIE2026の講座の宿題にある「3レベル」とは何ですか？` を入力する。
4. 3つ目の質問として `最初の質問は？` を入力する。
5. 3つ目の回答が、1つ目に入力した `LoRAとは何ですか` を指していることを確認する。これにより、複数ターンの履歴が後続の質問で参照されていることを確認する。
6. 各ターンの `[トークン]` 表示で、「履歴」は過去の会話だけ、「入力全体」は今回の質問も含むAPI入力全体を表すことを確認する。2ターン目以降は履歴数が増えることも確認する。
7. `/exit` または `/quit` を入力し、対話モードを終了する。

この手動確認は外部APIへのリクエストとAPIキーを必要とし、履歴のある質問ごとにトークン計数APIも呼び出す。APIを利用できない場合は、代わりに上記の自動テストで履歴の引き継ぎとトークン表示を確認する。
