# 第1回 宿題ガイド

宿題は「基礎・実装・発展」の3レベルから**1つ選んで**取り組みます。各ガイドで手順を確認し、結果と考察を [answer.md](../answer.md) に記録してください。

| レベル | 取り組む内容 | 手順 |
|---|---|---|
| 基礎 | 同じ質問を複数回実行し、モデルまたはtemperatureによる回答の違いを比べる | [基礎の手順](./basic.md) |
| 実装 | 会話履歴を保ったまま、続けて質問できるようにする | [実装の手順](./implementation.md) |
| 発展 | 複数のモデル・質問で応答時間とtoken数を比べ、レート制限との関係を考察する | [発展の手順](./advanced.md) |

## 実験用ファイルについて

手順書はこの `homework/` に、実験スクリプトと自動生成レポートは [`experiment/`](../experiment/) に置いています。実験スクリプトの詳細やレポートの見方は、選んだレベルの手順から確認してください。

提出先は [`answer.md`](../answer.md) です。実行条件や回答全文をすべて転記するのではなく、結果の要約・気づき・考察を書き、根拠となるレポートを参照してください。
